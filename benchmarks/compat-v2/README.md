# Compatibility benchmark v2

Fixtures live under `apps/compat-*`. They cover Tailwind, Monaco, React Hook Form, Zod, Next.js, TanStack Query, TanStack Virtual, TanStack Table, Recharts, and Bootstrap.

Run `scripts/check-compat` from the repository root. Install the browsers required by each app first.

The `compat-legacy-baseline` tag identifies the Bootstrap-only baseline.
