# Anta design exploration

Five frontend-only mock applications explore how coding agents use [Anta](https://anta.design/) in different product contexts. The goal is to review both the resulting interfaces and code, and identify the framework's strengths and weaknesses. These are UI prototypes, not working services.

Each app is developed in its own worktree and lives under `apps/`. See each app's README for setup, available UI states, and developer observations. Coloph-sync coordinates checked integration into the shared repository.
